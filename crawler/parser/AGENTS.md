## Package

**Language:** Go (module: `github.com/vitalyshatskikh/crawler-temporal-demo/crawler`)

### Setup

```bash
# Install golangci-lint, 'go install tool', and Python deps for crawler
make setup-dev

# Or manually:
go install github.com/golangci/golangci-lint/v2/cmd/golangci-lint@v2.12.2
go install tool
(cd crawler && poetry sync)
```

### Generate

```bash
# Generate code: sqlc (db/gen/) + mockery (testutil/)
make crawler-go-generate
# Equivalent: cd crawler && go generate ./...
```

### Build

```bash
# Build all packages
cd crawler && go build ./...

# Build specific binary
cd crawler && go build -o bin/parser ./parser/cmd/parser
```

### Test

```bash
# Run all unit tests (excludes /gen and /testutil packages)
make crawler-go-test-unit
# Equivalent: cd crawler && go tool gotestsum -- -v -race -coverprofile=coverage.out $(go list ./... | grep -v -E '/gen|/testutil')

# Run a single package
cd crawler && go test -v -race ./parser/internal/domain/...

# Run integration tests (requires Postgres via docker-compose)
make crawler-go-test-integration
```

### Lint/Format

```bash

make crawler-go-fmt
# Equivalent: cd crawler && go fmt ./... && go fix ./...

# Lint
make crawler-go-lint
```

## Code Style

### Formatting

- Use `go fmt` and `goimports` (configured in `.golangci.yml`)
- 4-space indentation (tabs converted to spaces)
- Max line length: **120 characters**
- Empty lines between logical code blocks

### Imports

- Group in order: **stdlib → third-party → local (`github.com/...`)**
- Use `goimports` to manage import groups automatically
- Remove unused imports

### Naming Conventions

| Entity | Convention | Example |
|---|---|---|
| Packages | lowercase, single word | `domain`, `infrastructure` |
| Exported types/functions | `PascalCase` | `ParsingService`, `ParseSearchPage` |
| Unexported types/functions | `camelCase` | `parsingService`, `getJMESParser` |
| Constants (multi-word) | `UPPER_SNAKE_CASE` | `ActivityParseSearchPage`, `QueueParsing` |
| Interfaces | `-er` suffix or `Repository` | `ConfigRepository`, `AdvertsRepository` |
| Test files | `_test.go` suffix | `parser_test.go` |
| Test functions | `Test<Subject>_<Method>_When<Cond>_Then<Outcome>` | `TestService_ParseSearchPage_WhenInvalidDoc_ThenErrValidation` |

### Type Annotations

- Always explicit on function signatures
- Use `errors.Is()` / `errors.As()` for error checking
- Use struct tags for JSON/DB mapping (`json:"..."`, `env:"..."`)

### Error Handling

- Use `fmt.Errorf()` with `%w` verb for wrapping errors
- Use `errors.Is()` to check for specific errors (including wrapped ones)
- Use `errors.As()` to extract error types
- Define sentinel errors with `var ErrName = errors.New("...")` in `domain/errors.go`
- Return errors from functions rather than logging them
- Use meaningful error messages

```go
var ErrNotFound = errors.New("item not found")

func processFile(filename string) error {
    file, err := os.Open(filename)
    if err != nil {
        return fmt.Errorf("failed to open file %s: %w", filename, err)
    }
    defer file.Close()
    // ...
}
```

### Logging

- Use `go.uber.org/zap` for structured logging in `main.go`
- Use `log/slog` with `zapslog` bridge for Temporal's structured logger
- Include relevant context (zap fields) without sensitive data

### Context

- Pass `context.Context` as the first argument to all functions that may block or call external services
- Check `ctx.Done()` in loops for cancellation (see `JMESParser.Parse`)

## Testing Conventions

- **Framework:** Go testing + `github.com/stretchr/testify` (`assert`, `require`, `mock`)
- **Mock generation:** `go generate` via mockery (configured in `.mockery.yml`) → `testutil/` packages
- **Test naming:** `Test<Type>_<Method>_When<Condition>_Then<Outcome>` (matches parent `crawler/AGENTS.md` convention)
- **Test data builders:** `testutil/factories.go` in each package — faker-based (`go-faker/faker/v4`) + `Must*` helpers for hardcoded values
- **Test layout:**
  - `*_test.go` in same package as code under test
  - `*_integration_test.go` with `//go:build integration` tag
  - Integration tests use `testutil.Setup()/Teardown()` which creates/drops a per-pid database
- **Coverage:** Exclude `/gen` and `/testutil` packages from coverage (per CI config)
- **Time:** Use `temporalio.testing.WorkflowEnvironment.start_time_skipping()` for Temporal-aware time testing (if needed)

```go
func TestService_ParseSearchPage_WhenConfigMissing_ThenErrNotFound(t *testing.T) {
    mockConfRepo := testutil.NewMockConfigRepository(t)
    mockConfRepo.EXPECT().GetConfig(mock.Anything, mock.Anything, mock.Anything).Return(domain.ParsingConfig{}, domain.ErrNotFound)
    svc, _ := domain.NewParsingService(mockConfRepo)
    // ...
}
```

## Error Handling

### Sentinel errors (`domain/errors.go`)

| Error | When |
|---|---|
| `ErrValidation` | Invalid input, missing required fields, schema violations |
| `ErrNotFound` | Config or document not found in database |
| `ErrParsingFailed` | JMESPath compilation/execution failure, JSON decode failure |

### Activity-level wrapping (`activities/parser.go`)

`wrapErr()` maps domain errors to `temporal.NewNonRetryableApplicationError`:

```go
func wrapErr(err error) error {
    if errors.Is(err, domain.ErrValidation) ||
        errors.Is(err, domain.ErrNotFound) ||
        errors.Is(err, domain.ErrParsingFailed) {
        return temporal.NewNonRetryableApplicationError(err.Error(), "ParsingError", err)
    }
    return err
}
```

These are **non-retryable** — Temporal will not attempt to replay them.

### Repository-level mapping

`pgx.ErrNoRows` → `domain.ErrNotFound` in both `PGConfigRepo.GetConfig` and `PGAdvertsRepo.GetDocument`.

## Cross-package Sync Contract

The parser uses the **same data model and activity names** as `crawler/surfer`. Changes here must be propagated to `crawler/surfer` in the same commit.

### Types that must stay in sync with `crawler/surfer`

| Parser type | Surfer type | Notes |
|---|---|---|
| `type SdocID string` | `SdocID = tp.NewType("SdocID", str)` | Content-addressable ID: MD5 of normalized URL |
| `type SourceID string` | `SourceID = tp.NewType("SourceID", str)` | Identifies a scraping source |
| `type DocumentType string` + consts | `DocumentType` StrEnum | Values: `search_page`, `surfed_advert`, `downloaded_advert`, `parsed_advert` |
| `DocumentMeta` struct | `DocumentMeta` pydantic model | Fields: `sdoc_id`, `created_at`, `updated_at`, `source_id`, `type`, `external_url`, `content_url`, `update_interval_sec` |
| `Document` struct | `Document` pydantic model | `DocumentMeta` + `body []byte` |

### SdocID semantics (shared)

`SdocID` is computed by `SdocIDForURL()`: MD5 hash of a **normalized** URL (lowercased scheme+host, stripped fragment, sorted query params, trailing-slash normalized). Used as content-addressable identity across surfer, downloader, and parser.

### DocumentMeta field semantics (shared)

- `external_url` — canonical URL used as **identity** (stable across re-downloads)
- `content_url` — URL to **fetch body from** (may differ from external_url; e.g., API endpoint vs display URL)
- `update_interval_sec` — advisory crawl interval

### Activity names that must stay in sync

| Parser constant | Surfer constant | Notes |
|---|---|---|
| `ActivityParseSearchPage = "ParseSearchPage"` | `ActivityName.PARSE_SEARCH_PAGE = "ParseSearchPage"` | Comment in both files: "Keep in sync" |
| `ActivityParseAdvertContent = "ParseAdvertContent"` | `ActivityName.PARSE_ADVERT_CONTENT = "ParseAdvertContent"` | Same |

### Queue name

| Parser queue | Surfer queue | Notes |
|---|---|---|
| `QueueParsing = "parsing"` | `QueueName.PARSING = "parsing"` | Used by surfer to enqueue parse activities |

When changing either side, update the other in the **same commit**.
